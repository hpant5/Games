# Parking Jam

Godot 4.6 casual Android puzzle prototype.

## Run

Open this folder in Godot and run `scenes/main.tscn`.

## Controls

- Tap/click a car to select it.
- Press `Tab` or `Space` to cycle cars.
- Press `1`-`9` to select a car by order.
- Use `W` / Arrow Up to drive forward.
- Use `S` / Arrow Down to reverse.
- Use `A` / Arrow Left and `D` / Arrow Right to steer.
- Move the red target car out through the green exit.
- Press `R` to restart.

## Prototype Scope

- 6x6 board
- 3 starter levels
- Car blocking rules
- Move counter
- Level progression
